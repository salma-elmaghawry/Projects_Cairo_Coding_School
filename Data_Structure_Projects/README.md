# Data Structures Practice Projects

Solutions for the three Level 2 practice projects (Cairo Coding School, sessions 15 and 16).

| # | Project | Data structure | File |
|---|---|---|---|
| 01 | My Playlist | Linked List | `Playlist_LinkedList.cpp` |
| 02 | Browser Back Button | Stack | `BrowserBack_Stack.cpp` |
| 03 | Bank Waiting Line | Queue | `BankLine_Queue.cpp` |

## How to run

```bash
g++ Playlist_LinkedList.cpp -o playlist
./playlist
```
